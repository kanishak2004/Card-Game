# Card-Game
🃏 War Card Game – iOS Application
📱 Project Overview

War Card Game is a simple yet engaging iOS card game developed using Swift and SwiftUI. The game is based on the classic War card game, where the player competes against the computer by drawing cards, and the higher card wins the round.

This project focuses on strengthening iOS fundamentals, Swift programming, and UI development using SwiftUI, making it ideal for beginners and freshers.

🎮 Game Rules

The player and the computer draw one card each per round.

The card with the higher value wins the round.

The winner receives 1 point.

In case of a tie, no points are awarded.

Scores are updated in real time.

🚀 Features

Simple and intuitive UI built with SwiftUI

Random card generation logic

Real-time score tracking

Smooth animations for card changes

Clean and readable code structure

Beginner-friendly implementation
